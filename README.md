# نقشه پروژه AI برای رزومه و مسیر آمریکا

راهنمای تعاملی برای دانشجوی ارشد هوش مصنوعی در ایران (به‌خصوص ترم ۳) که می‌خواهد رزومه‌اش را برای مقصد نهایی آمریکا قوی کند.

هر پروژه چهار نمره از ۱۰ دارد:

- **اهمیت** — آیا ارزش وقت پایان‌نامه را دارد؟
- **تأثیر رزومه** — چقدر در ۳۰ ثانیه اسکن می‌شود و باورپذیر است؟
- **PhD** — کمیته پذیرش و نامه توصیه
- **صنعت** — نقش‌های ML Engineer / Applied Scientist

امتیاز کلی با توجه به هدف (پژوهش، صنعت، یا هر دو) وزن می‌شود.

## اجرا

```bash
npm install
npm run dev -- --port 43147
```

سپس [http://127.0.0.1:43147](http://127.0.0.1:43147) را باز کنید.

## ساخت نسخه تولید

```bash
npm run build
npm start -- --port 43147
```

این ابزار مشاوره است نه تضمین پذیرش یا ویزا. استخدام مستقیم شرکت آمریکایی از داخل ایران معمولاً به‌خاطر محدودیت‌های تحریمی سخت است؛ پروژه‌ها مسیرهای واقعی‌تر (PhD با فاند، پله اروپا/کانادا، آرتیفکت عمومی) را تقویت می‌کنند.
